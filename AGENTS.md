# AGENTS.md

## Rules

1. **Never push to remote without explicit user approval.** Always ask before running `git push` or creating/remoting any branch.

2. **Always run lint before committing.** Execute `npm run lint` and ensure zero errors before any commit.

3. **Keep DESIGN.md in sync.** Whenever a design change is made (colors, spacing, typography, layout, component structure, motion, responsive behavior), update `DESIGN.md` to reflect the new state. The design doc is the single source of truth for the visual system.
